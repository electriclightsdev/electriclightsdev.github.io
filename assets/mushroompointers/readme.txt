Author's description:

This '''Animated Mushroom''' cursor set is a set created by '''Rope-Shrine-Maiden''' on '''DeviantArt'''. I am sharing it here to spread it popularity. This set comes with 15 cursor roles. All the cursors are red with red and white mushrooms like in '''Super Mario''' games. The original set is found below:

https://www.deviantart.com/rope-shrine-maiden/art/Animated-Mushroom-Cursors-113194797

The hotspots were completely messed up for this cursor set, so I had to fix them all. There was an error whilst opening the cursors in '''RealWorld Cursor Editor''', so I had to download a third part portable program from '''PortableApps''' from the link below:

https://portableapps.com/apps/graphics_pictures/greenfish-icon-editor-pro-portable

The application I used to re-save the cursors to make them valid again to open in '''RealWorld Cursor Editor''' is called '''Greenfish Icon Editor Pro Portable''', so that program fixed the opening error. The error that I got in '''RealWorld Cursor Editor''' was '''The application failed to execute the requested action for unspecified reason. Please verify that all external conditions for the attempted operations are valid.''', very strange, and I never had that error before for opening any cursor type in '''RealWorld Cursor Editor''' before.

Now, this cursor set works properly, so I have tested all the cursors to make sure that there are no longer any invalid errors again. Enjoy it now.
